# Dataset inicial

`personality.jsonl` é um conjunto sintético original escrito para este projeto, disponibilizado sob a licença do projeto. São exemplos pequenos de estilo, não uma base representativa, nem dados suficientes para desenvolver conhecimento amplo, segurança ou raciocínio confiável. Separação de validação por exemplo é realizada no treinamento. Para adicionar dados, verifique origem, licença, privacidade e qualidade; use JSONL com `prompt` e `response`. Não inclua segredos ou dados pessoais sem autorização. A licença deste repositório não altera a licença de dados externos.
